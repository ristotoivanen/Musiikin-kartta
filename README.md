# Musiikin kartta

Musiikin kartta on avoin suomenkielinen verkko-opas musiikin teoriaan ja kitaransoittoon. Yhdeksän perusosaa etenevät ensimmäisestä kappaleesta sointuihin, otelautaan, korvakuulolta soittamiseen ja oman kappaleen äänittämiseen. Kaksi valinnaista osaa syventää septimisointuihin ja moodeihin. Mukana on kuunteluesimerkkejä, kitaraharjoituksia ja säestystaustoja.

**[Lue opas verkossa](https://rinnepelto.com/)** · [Musiikin teoria](https://rinnepelto.com/book/) · [Avaa Otelautakartta](https://rinnepelto.com/otelautaharjoittelija.html)

Suunnitteluun ja katselmointiin: [käytettävyyden, saavutettavuuden ja pedagogiikan yhteinen ohje](docs/suunnittelu/suunnittelu-ja-pr-katselmointi.md). Hyväksyntä- ja käyttöönottotila kerrotaan ohjeen alussa ja §10:ssä.

## Otelautakartta

[Otelautakartta](otelautaharjoittelija.html) yhdistää vanhat
`Kokeile otelautaa`- ja `Soita taustan mukana` -sivut yhdeksi
visualisointityökaluksi. Kartassa ei ole harjoitustehtäviä,
äänisoittimia tai säestystaustoja. Asteikko-näkymässä valitaan kotisävel
ja asteikko tai moodi. Oktaavit-näkymä näyttää saman sävelen eri korkeuksilla.

**Soinnut-näkymä toimii asteikoista riippumatta.** Valitse soinnun
perussävel ja duurin tai mollin laatu. Kolme näyttötapaa ovat:
**Kaikki sointusävelet** (koko otelauta),
**Koko ote** (mahdollinen avoin ote ensin ja sitten saman soinnun
E- ja A-muotoiset barré-otteet nuolilla) sekä
**Triadi (G–B–e)** (vain kolmen ohuimman kielen sointusävelet ja
niiden käännökset nuolilla). Kaikissa näyttötavoissa käytetään samaa
nauhamäärää, eikä sointua sidota valittuun moodiin.

Sormitusboksit löytyvät valinnaisista näyttöasetuksista. Pentatonisilla
asteikoilla käytetään automaattisesti **viittä pentatonista boksia**,
seitsemänsävelisillä moodeilla **seitsemää 3NPS-boksia**.
Yksittäisiä tai useita bokseja voi korostaa ja halutessaan näyttää
vain valittujen boksien sävelet. Otelaudan oletuslaajuus on
**17 nauhaa molemmille asteikkotyypeille**, eikä kaulan koko vaihdu
pelkän asteikon valinnan seurauksena. Nauhamäärän voi vaihtaa erikseen.

Vanha [harjoitustaustat.html](harjoitustaustat.html) ohjaa
Otelautakarttaan säilyttäen linkin kotisävelen ja asteikon.
Varsinaiset soittamiseen ja kuunteluun tarkoitetut harjoitukset ovat
erillisessä [Kitaraharjoittelijassa](kitaraharjoittelija.html)
sekä oppaan lukujen ääniesimerkeissä.

## Kappaleharjoittelu

**Kappaleharjoittelu** on Kitaraharjoittelijan neljäs oppimispolku.
Sen ensimmäinen mallikappale on **Yksi sointu, kaksi askelta** sekä
akustisena että normaalina versiona. Valitussa sovituksessa säestys, kitara
ja laulu ovat kolme samanaikaisesti toistettavaa MP3-raitaa. Kitara ja laulu
voidaan vaimentaa erikseen kesken kappaleen. Version vaihtaminen pysäyttää
toiston, palauttaa sen alkuun ja edellyttää uutta Soita-painallusta.
**Lataa MP3** -linkki lataa valitun version valmiin kokonaisen kappaleen.
Kappaleen äänitiedostot ovat GitHub-repossa hakemistossa
`assets/audio/kappaleet/`, ja Cloudflare Pages julkaisee ne sieltä. Niitä on
kahdenlaisia: soittimen **harjoitusraidat** (`…-saestys.mp3`, `…-kitara.mp3`,
`…-laulu.mp3`) ja **Lataa MP3** -linkin **kokonaiset kappaleet**
(`…-kokonainen.mp3`). Molemmat tulivat alun perin erillisinä ZIP-paketteina:
raidat versiokohtaisina raitapaketteina ja kokonaiset kappaleet omana
latauspakettinaan. Kokonaiset MP3:t ovat alkuperäisiä sellaisenaan, eivätkä
ne ole raitojen miksaus. Äänitteiden käyttöehdot:
[AANITTEET-LISENSSI.md](assets/audio/AANITTEET-LISENSSI.md).
Asennusohje on [harjoittelijan README:ssä](harjoittelija/README.md).

## Paikallinen käyttö

Avaa kloonatun repon `index.html` selaimessa. Oppaan sivut ovat [book-kansiossa](book/) ja kuunteluesimerkit [assets/audio-kansiossa](assets/audio/). Sisäiset linkit ja edistymisen lukutaulukon voi tarkistaa komennolla `python3 tools/linkit/tarkista-linkit.py`.

Sivuston kolmella pääosiolla (Oppimiskartta, Otelautaopas ja Kitaraharjoittelu) on sama päävalikko. Sen merkintä toistuu jokaisen sivun alussa, ja tyylit ovat tiedostossa `assets/paavalikko.css`. Perinteisen teoriaoppaan aloitusnäkymä on `book/index.html`. Osat on ryhmitelty siinä neljäksi avattavaksi kokonaisuudeksi, ja `assets/edistyminen.js` täydentää jatkamiskortin ja osien merkinnät tallennetuista lukumerkinnöistä. Kun oppaaseen lisätään osa, lisää se sekä `edistyminen.js`:n PARTS-taulukkoon että aloitusnäkymän kokonaisuuteen. `npm test` tarkistaa, että ne vastaavat `book/osa-*.html`-tiedostoja.

## Oppimiskartan ylläpito

Oppimiskartta kulkee etusivun kortista aiheen sivulle ja sieltä lyhyeen oppituntiin, harjoitukseen tai olemassa olevaan harjoittelijaan. [Perinteinen 11-osainen teoriaopas](book/index.html) tarjoaa samat luvut alkuperäisessä lukujärjestyksessä.

| Aihe | Aihesivu |
| --- | --- |
| 01 Kitaran perusteet | [kitara](oppi/kitara/index.html) |
| 02 Rytmi | [rytmi](oppi/rytmi/index.html) |
| 03 Sävelnimet ja sointumerkinnät | [savelnimet](oppi/savelnimet/index.html) |
| 04 Sävelkorva ja melodia | [korva](oppi/korva/index.html) |
| 05 Otelauta | [otelauta](oppi/otelauta/index.html) |
| 06 Soinnut ja harmonia | [soinnut](oppi/soinnut/index.html) |
| 07 Asteikot ja moodit | [asteikot](oppi/asteikot/index.html) |
| 08 Kappaleet ja oma musiikki | [kappaleet](oppi/kappaleet/index.html) |

**Lisää tai muokkaa sisältöä**

1. Muokkaa opetustekstiä, harjoituksen ohjetta ja lähteitä tiedostoissa `book/osa-*.html`. Pidä `section.chapter`-luvun `id` ja `Luku N` -merkintä vakaina. Uusi luku tarvitsee myös merkinnän `assets/edistyminen.js`:n PARTS-taulukkoon ja teoriaoppaan sisällysluetteloon.
2. Lisää tai siirrä luvun `osa-N#tunniste` ja oppimistavoite [aiheluetteloon](tools/oppimiskartta/aiheet.json). Uuden aiheen hakemistopolku määräytyy sen `slug`-arvosta. Lisää aiheen paluulinkin taivutettu teksti kenttään `back_label`. Ryhmien, lukujen ja harjoitusten järjestys määrää aiheen numeroinnin sekä Edellinen- ja Seuraava-linkit. Ristiinlinkitä toisen aiheen sisältö sen polulla.
3. Anna luvun erilliselle harjoitukselle yksilöllinen `data-oppisisalto="tunniste"` ja aloita se `<h3>Harjoitus · Nimi</h3>`-otsikolla. Lisää tunnisteelle lyhyt toimintaa kuvaava teksti aiheluettelon `exercise_descriptions`-kohtaan. Generaattori jättää harjoituksen teoriaoppaaseen ja tekee Oppimiskartan lukuun linkin omalle harjoitussivulle. Jos tehtävä tarvitsee kuunneltavan esimerkin, lisää aiheluettelon `exercise_audio`-kohtaan lähdekuvion viite `osa-N#ankkuri`. Kitaran merkintöjen opetussivu poimitaan kommenttirajojen välistä osasta 1.
4. Lisää vain Oppimiskarttaan kuuluva oppitunti aiheluettelon ryhmään kentillä `standalone`, `title` ja `goal`. Käytä `standalone`-kentässä pysyvää sivutunnistetta. Kirjoita HTML-katkelma tiedostoon `tools/oppimiskartta/sisallot/<aiheen-slug>/<standalone>.html`. Generaattori lisää sivuotsikon, oppimistavoitteen, navigoinnin ja suorituspainikkeen. Aloita väliotsikot tasolta `h2` ja kirjoita linkit suhteessa lähdetiedostoon. Pidä tunniste vakiona, sillä se muodostaa sekä osoitteen että suoritusmerkinnän.
5. Aja `npm run build:oppimiskartta` ja tallenna myös muodostuneet HTML-sivut ja navigaatiolohkot versionhallintaan. `npm run build` ajaa saman vaiheen. `npm test` tarkistaa lähteiden ja sivujen vastaavuuden, kaikki 28 teoriaoppaan lukuviitettä sekä sisäisten linkkien ja ankkurien toimivuuden.

Aiheet 01–08 ja aiheen sisäiset askeleet ovat suositellussa järjestyksessä. **Teoriaoppaan luku** kertoo kirjan lukujärjestyksen. Oppimiskartan kaikki numeroidut sisällöt voi merkitä tehdyiksi ja merkinnän voi perua. Selaimen `musiikin-kartta:luvut`-listalla säilyvät teoriaoppaan alkuperäiset lukutunnisteet. Harjoitusmerkinnän tunniste on `harjoitus:<slug>` ja muun opetussivun `oppitunti:<slug>`. Sama sisältösivu käyttää samaa tunnistetta kaikista linkeistä. Aiemman `musiikin-kartta:tehdyt`-avaimen migraatio säilyy. Teoriaopas ja etusivun jatkamislinkki seuraavat kirjan 28 lukua.

Aihe valmistuu, kun sen kaikki omat numeroidut luvut, oppitunnit ja harjoitukset on merkitty tehdyiksi. Aihekortin ja aihesivun laskurin sisältöluettelo muodostetaan `aiheet.json`-tiedoston omista oppitunneista ja niiden harjoituksista. **Tutki myös** -linkit ja ulkoiset työkalut ovat laskurin ulkopuolella.

Sisältösivun ylä- ja alanavigointi seuraavat aiheen sisältöjärjestystä. Aiheen viimeisellä sivulla seuraava linkki avaa seuraavan aiheen etusivun `aiheet.json`-tiedoston järjestyksessä. Linkki on käytettävissä myös ennen aiheen valmistumista, ja sitä pitkin avattu aihe jää näkyviin Oppimiskartassa. Viimeisellä sisältösivulla on paluu Oppimiskarttaan sekä koko polun valmistumismerkintä, joka näkyy, kun kaikki numeroidut sisällöt on merkitty tehdyiksi.

Etusivu näyttää ensin kolme aihetta. Jokainen valmistunut aihe paljastaa korkeintaan kerran ensimmäisen vielä piilossa olevan aiheen. Aiemmin esiin tulleet ja jo aloitetut aiheet jäävät näkyviin suppeassa näkymässä. Suora kartta-ankkuri näyttää kohdekortin. **Näytä kaikki aiheet** avaa muut kortit, ja selaimeen muistetaan käyttäjän näyttövalinta. Avaimessa `musiikin-kartta:aihenakyma` on ainoastaan listan näyttötila. Ilman JavaScriptiä kaikki kahdeksan korttia näkyvät.

Vanhojen `book/osa-N.html#ankkuri`-linkkien sisältö säilyy kirjassa. Vanha kartta-ankkuri kohdistuu vastaavaan korttiin ja työkalun `?aihe=aihe-…`-parametri ohjaa paluun aihesivulle. Pidä nykyiset polut käytössä myös silloin, kun aiheen nimi muuttuu. Sivut ja linkit toimivat staattisina. Lukumerkinnät ja kolme selaimessa ääntä muodostavaa korvaharjoitusta tarvitsevat JavaScriptin.

[Oppimiskartan sisältö- ja käyttökatselmus](reviews/oppimiskartan-katselmus.md) kuvaa sisältöjen sijoittelun, löydetyt ongelmat ja seuraavat arviointikohteet.

Sivujen tyylitiedostolinkeissä on versiotunniste (`reader.css?v=…`), joka lasketaan tiedoston sisällöstä. Näin palaava kävijä ei saa uutta sivua vanhalla, välimuistissa olevalla CSS:llä. Kun muutat CSS-tiedostoa, aja `node tools/versioi-tyylit.mjs`. `npm run build` ajaa sen automaattisesti, ja `npm test` huomauttaa vanhentuneesta tunnisteesta.

## Interaktiivinen kitaraharjoittelu

[Kitaraharjoittelija](kitaraharjoittelija.html) yhdistää otelaudan sävelet,
pentatoniikan ja moodit, sointusävelet, CAGED-duurimuodot sekä korvaharjoittelun.
Vastaa otelautaruudukolla tai soita yksi sävel kerrallaan mikrofoniin / äänikorttiin.
Mikrofoni tunnistaa sävelkorkeutta, eikä sen perusteella voida varmistaa käytettyä
kieltä tai nauhaa. Ääntä ei tallenneta eikä lähetetä palvelimelle.

Harjoittelutapoja on kolme. **Testaa osaamistasi** on oletus: oikea kohta ei näy,
ja vihjeen saa pyytämällä. **Opettele** näyttää vastauksen heti, ja **Vähennä
vihjeitä** poistaa vihjeet asteittain. Vihjeen kanssa annetut vastaukset tilastoidaan
erikseen. **Testaa mikrofoni** näyttää äänitason, tunnistetun sävelen, taajuuden ja
vireen ennen harjoitusta, eikä se vaikuta tuloksiin.

Tulokset tallentuvat paikallisesti selaimeen. Oppaan vanhat lukumerkinnät säilyvät.
Harjoittelijan käyttö tarvitsee HTTP-palvelimen; mikrofonikäyttö tarvitsee
localhost-osoitteen tai HTTPS:n. Valmiit build-tiedostot ovat repossa, joten
paikalliseen kokeiluun riittää:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
# Avaa http://127.0.0.1:8000/kitaraharjoittelija.html
```

Kehitys tarvitsee Node.js 22.16+ (tai yhteensopivan uudemman LTS:n), npm:n ja Python 3.9:n tai uudemman.

```bash
npm ci
npm run dev
# Avaa http://127.0.0.1:5173/kitaraharjoittelija.html
```

```bash
npm run check       # ESLint, yksikkötestit, TypeScript ja staattinen tuotantobuild
npm run test:e2e    # työpöytä + puhelin, paikallinen HTTP-palvelin käynnistyy itse
PRACTICE_TEST_DEV=1 npm run test:e2e # samat selaintestit Viten lähdekoodipalvelimella
npm run coverage    # yksikkötestien kattavuus logiikkamoduuleille
npm audit          # myös kehitysriippuvuuksien tarkistus
```

E2E-testit käyttävät Macille asennettua Chromea, jos se löytyy. Muissa ympäristöissä
asenna testiselain komennolla `npx playwright install chromium` tai anna
`PLAYWRIGHT_CHROME_EXECUTABLE`-ympäristömuuttujassa oman Chromiumin polku.
Puhelintesti on Chromiumin laite-emulointi, ei fyysisellä iPhonella tehty Safari-testi.
Testiselain käynnistyy ilman äänilähtöä, ja mikrofonitestit käyttävät simuloitua
signaalia. Ne eivät korvaa oikealla kitaralla tehtävää hyväksyntätestiä.

`npm run build` kääntää Kitaraharjoittelijan hakemistoon `assets/harjoittelija/`,
Riffikaiun hakemistoon `assets/riffikaiku/` ja Ensikeikan hakemistoon `pelit/ensikeikka/`.
Ensikeikan lähdekoodi on hakemistossa `ensikeikka/`. Komento `npm run build:ensikeikka`
päivittää pelkästään Ensikeikan julkaisuhakemiston. Pelin voi avata käännöksen jälkeen
paikallisella staattisella palvelimella osoitteessa `/pelit/ensikeikka/`.
Build ei julkaise sivustoa. Cloudflare Pages ajaa lisäksi
[`functions/assets/audio/[[path]].ts`](functions/assets/audio/[[path]].ts)-funktion, joka
palvelee äänitiedostojen tavualueet (HTTP 206). Ilman sitä kappaleharjoittelun
kelaus ja raitojen synkronointi eivät toimi Pagesissa. Funktio ei näy paikallisessa
`python3 -m http.server`-palvelimessa, joka ei myöskään tue tavualueita. [Auditointiraportti](reviews/kitaraharjoittelija-auditointi.md)
kuvaa nykytilan, testitulokset, mikrofonitunnistuksen rajoitukset ja oikealla
kitaralla tehtävät hyväksyntätestit. [Kehittäjän ohje](harjoittelija/README.md) kuvaa
rakenteen ja tallennusmuodon, ja [alkuperäinen kehitysraportti](reviews/fretecho-kehityskatselmus.md)
URL-parametrit ja integraation taustan.
