# Kuunteluesimerkit ja harjoitustaustat

Kunkin osan ääniesimerkit ovat omassa kansiossaan hakemistossa `audio/`. Esimerkiksi `audio/osa-4/` sisältää Korvakuulo-osan kuunteluharjoitukset ja Paluumatkan.

Jokaisesta esimerkistä on kaksi tiedostoa. Kirjan sivut soittavat ensisijaisesti kevyen AAC-version (`.m4a`), ja mono-WAV (`.wav`) on varalla selaimille, jotka eivät tue AAC:tä.

Esimerkit tehdään generaattorilla, joka käyttää samoja soittimia kuin harjoitustaustat (`harjoitustausta.js`). Esimerkkien nuotit ja otteet ovat tiedostossa `../tools/aanet/esimerkit.js`. Ohjeet uudelleenrenderöintiin ovat tiedostossa `../tools/aanet/README.md`.
