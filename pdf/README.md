# Tulostettava opas

`musiikin-kartta.pdf` on koko opas yhtenä tulostettavana tiedostona. Se kootaan automaattisesti `book`-kansion sivuista, joten älä muokkaa PDF:ää käsin. Ohjeet ovat tiedostossa [`../tools/pdf/README.md`](../tools/pdf/README.md).

Kokoa PDF uudelleen aina, kun muutat oppaan sivuja, ja tallenna se samaan muutokseen.
