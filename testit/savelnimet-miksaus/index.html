Miksauksen kuuntelukoe

Väliaikainen testisivu PR #205:lle, ei osa tuotantosisältöä. Käytä samaa äänenvoimakkuutta kaikissa kokeissa. Kuuntele ensin A, sitten muut. Kirjaa mielipiteesi alla oleviin kysymyksiin.

  • A nykyinen miksaus.
  • B kaikki +6 dB (kokonaisvoimakkuus ylös, suhteet samat).
  • C vain lopetussointu +4 dB.
  • D komppi +3 dB, kitara ennallaan.

Kysymykset

  1. Onko A riittävän kuuluva normaalilla puhelimen äänenvoimakkuudella?
  2. Erottuuko melodian keskimmäinen sävel (C / C♯ / D)?
  3. Erottuuko lopetus-D (A vs C)?
  4. Onko komppi liian hiljainen tai liian hallitseva (A vs D)?
  5. Erottuuko riffin toinen sävel (F / F♯ / ylempi D)?
